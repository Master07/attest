Attest — every PR ships with proof.

An autonomous delivery agent that won't call a task done until a computer-use verifier has driven the running app and confirmed it — then hands you a replayable record of how it passed.

How it works Why this stack Models

The problem

<55%
share of logical mutants caught by frontier agents' own tests — so code passes CI and still doesn't work. [nielstron, 2026]
Generation got solved. Trust didn't.

Agents write code faster than anyone can review it. The bottleneck is no longer producing a change — it's believing it works. Attest makes “done” = verified in the running app, not green CI.

The loop

01

Plan

Grounded in the real repo, approval-gated before any code changes.

02

Fan out

One write-capable subagent per task, each in its own isolated git worktree.

03

Verify

A separate computer-use agent boots the app, drives the flow, confirms the UI with SAM 3.1.

04

Attest

Evidence derived from the event log: diff + execution trace + before/after video.

Flow

work item→ plan→ fan-out · worktrees→ merge→ ↻ CUA verify→ PR + evidence

Fail the gate → the task reopens automatically with the verifier's evidence attached. The producing agent can never declare its own success.

Why only this stack can build it

Worktree fan-out

Real parallel isolation — workers never collide, the parent's copy stays clean, merges are explicit.

Replayable event log

The attestation is derived from the log, not written beside it — so the model can't fake the evidence.

Computer-use

Verification at the level the user experiences: the running app, driven like a person would.

Multimodal in / out

A screen recording of the desired behaviour goes in; a proof video comes out.
